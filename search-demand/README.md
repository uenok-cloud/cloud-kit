# 検索数チェック（商談用）

地域とサービス名を入れると、**「○○市で○○を探している人は月に約△△回検索している」** を数秒で画面に出すツール。
商談中にその場で見せる用途に絞ってある（記事やサンプルは作らない）。

既存の「商談サンプル」（shodan.mugenkaitaku.com）はURLと事前情報から AI がキーワードを選び、
検索数を確認し、記事構成まで作るので 1〜2 分かかる。こちらは同じ検索数データ（DataForSEO 経由の
Google 広告データ）を、キーワード生成を定型にして **数秒** で返す。

## 画面に出るもの

1. 見出し：`「外壁塗装 千葉市」 月 約720回`（直近月の数字、地域を含む関連語の合計も併記）
2. 「大きく表示（商談モード）」で数字だけを全画面に
3. 問い合わせ直前に打たれる言葉（おすすめ・費用・相場・料金・口コミ・評判・業者・安い・比較）ごとの月平均と 12 か月の推移
4. 都道府県の中からその地域に絞った「サービス名だけ」の検索数（例：千葉県内で「外壁塗装」）
5. Google の検索窓に実際に出る候補（無料・キー不要）

## 動かし方

```bash
cd search-demand
pip install -r requirements.txt
cp .env.example .env        # DataForSEO の ID/パスワードを入れる（商談サンプルと同じもの）
set -a; . ./.env; set +a
uvicorn app:app --host 0.0.0.0 --port 8010
```

http://localhost:8010/ を開く。`?service=外壁塗装&area=千葉市` を付けたリンクを開くと自動で調べる
（商談前にリンクを作っておける）。

DataForSEO 未設定でも起動し、Google の検索候補だけ表示する。検索数は「未取得」と出る。

## API

`GET /api/lookup?service=外壁塗装&area=千葉市&extra=屋根塗装 千葉市&pref=千葉県`

- `service` 必須。`area` 任意（空なら全国）。`extra` はカンマ区切りで追加の語。`pref` は市名から都道府県を推定できない時だけ。
- 戻りは JSON（`main` が見出し用、`rows` が一覧、`region` が都道府県絞り込み、`suggest` が検索候補）。

## 数字の出どころと注意

- 検索数は Google 広告キーワードプランナーと同じデータ（DataForSEO `keywords_data/google_ads/search_volume/live`、日本・日本語・直近 12 か月の月平均）。概数で、月ごとに上下する。
- 「○○市」を含む語の数字は **全国のどこからでも** その語で検索した回数。都道府県絞り込みの数字は **検索した場所** で絞った回数。意味が違うので画面でも分けている。
- 数字が返らない語は Google 広告の扱いで月 10 回未満。「少ない」と出す（ゼロとは言わない）。
- 結果は `cache/volumes.sqlite` に 30 日間保存。同じ語を何度見せても API 代はかからない。
- 商談での使い方の約束事（根拠としてだけ使う、来訪数・問い合わせ数の見込みは言わない、成果の約束はしない）は画面下に常に表示。
